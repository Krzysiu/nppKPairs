# Changelog

## 0.2

- Renamed the plugin to KPairs.
- Added groups with shared settings and individual overrides.
- Added Normal and Extended replacement modes alongside Regex.
- Added whole-document scope and a temporary scope selector.
- Added AND, OR and FULL library search.
- Added favourite toggling directly in the list; favourites are not repeated by default.
- Added sorting by name and creation date.
- Added configurable flags, colour previews and a Flag Guide.
- Added a folder picker that appends directories without duplicates.
- Added local usage statistics and copyable reports.
- Added configurable double-click actions, including Preview, and an optional completion beep.
- Added simple-format import and import/export buttons in Settings.
- Added English and Polish translations, automatic language detection and language selection.
- Added modeless editors and report windows.
- Added Show all to bypass file and directory filters.
- Added release metadata, documentation and build instructions.
- Improved the panel layout at narrow widths.
- Changed the empty-search-result message to a non-clickable list entry.
- Removed directory-existence checks when saving filters.
- Updated About, credits and licence information.
- Removed the engine-test command from the plugin menu.
